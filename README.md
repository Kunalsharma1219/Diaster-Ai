Disaster AI

Overview


Disaster AI is an AI-based disaster assessment and response system that combines machine learning, computer vision, geospatial analysis, and path planning to analyze disaster-affected regions and support response operations.
The system processes visual and geographic information to perform damage detection, terrain analysis, land-cover analysis, road analysis, cost-map generation, and response-path planning. The results are presented through a web-based interface with interactive map visualization.
Objectives
- Analyze disaster-affected regions using AI and machine learning techniques.
- Detect and assess damage from disaster-related imagery.
- Analyze terrain and elevation information.
- Incorporate land-cover information into disaster assessment.
- Analyze road networks in affected regions.
- Generate cost maps based on geographic and environmental conditions.
- Plan suitable routes for disaster response operations.
- Provide an interactive interface for visualizing analysis and results.

Core Components


Damage Detection
The system uses computer vision and machine learning techniques to analyze disaster-related imagery and identify areas affected by damage.
Terrain and Elevation Analysis
Terrain and elevation information is processed to understand the geographic characteristics of an affected region and incorporate them into subsequent analysis.
Land-Cover Analysis
Land-cover information is incorporated to distinguish different geographic regions and support disaster assessment and route planning.
Road Analysis
The system processes road-related information to construct a representation of the available road network in the affected region.
Cost Map Generation
A cost map is generated by combining relevant geographic and environmental information. The resulting cost representation is used for route analysis and path planning.
Path Planning
Path-planning algorithms use the processed geographic information and cost maps to determine feasible routes for disaster-response operations.
Web Interface
The project includes a web-based interface for interacting with the system and visualizing analysis results through maps and result pages.

Installation


Clone the Repository
git clone https://github.com/<username>/disaster-ai.git
cd disaster-ai
Create a Virtual Environment
python3 -m venv venv
Activate the environment:
source venv/bin/activate
Install Dependencies
pip install -r requirements.txt
Running the Project
Run the main application using:
python3 main.py
The application can then be accessed through the local URL provided by the server.


Demo


A demonstration pipeline is available in the demo directory.
python3 demo/run_demo.py
The demo provides an example of the system's processing and analysis workflow.

The experiments directory contains scripts used during model development and experimentation, including:

Limitations


The performance of the system depends on the quality and availability of the underlying datasets. Model predictions may vary when applied to geographic regions, disaster types, or environmental conditions that differ significantly from the training data.
This project is intended for educational and research purposes and should not be used as the sole basis for real-world emergency-response decisions.
